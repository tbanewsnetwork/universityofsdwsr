Setting up the institution on GitHub

For staff

The university is designed so that the whole institution can be operated from a GitHub organisation. Follow these steps once, then repeat step four each term.

  • Step 1

    Create the organisation

    Create a GitHub organisation named for the university and add Dr. Samuel D. Wilson Sr. and SDW Jr. as owners.

  • Step 2

    Publish this website

    Push this repository, then enable GitHub Pages so the site is the organisation's public face.

  • Step 3

    Turn on GitHub Classroom

    Link GitHub Classroom to the organisation and create one classroom per track.

  • Step 4

    Create assignments

    Each course becomes a template repository; each weekly task becomes an assignment that clones that template for every student.

  • Step 5

    Mirror into Google Classroom

    Post the same deadlines in Google Classroom so students who are more comfortable there are never left behind.

Student questions

Do I need my own computer?

No. Every foundation course can be completed on an Android phone using the GitHub mobile site and a browser-based editor. A shared computer makes later courses easier, and the university will tell you when that point arrives.

What if my internet is unreliable?

Lessons are text-first and can be downloaded and read offline. Videos are published in a low-data version. Deadlines allow for a full week of interruption.

Is my coursework public?

Yes, by default — that is how it becomes your portfolio. If you need a repository kept private for personal reasons, ask the registrar and it will be arranged.

Can I study while working?

Yes. Courses expect roughly eight to ten hours a week and nothing is scheduled at a fixed hour.
