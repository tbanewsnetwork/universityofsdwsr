Programs

Six tracks, each a sequence of courses that ends in a project you can show an employer.

Certificate tracks

Study one track at a time
TRACK FE · 28 weeks

Frontend development

The founding program. Take a student from no experience to a deployed, accessible web application.

  • HTML and CSS from zero
  • JavaScript for the browser
  • Responsive interfaces and accessibility
  • React and component thinking
Foundation to intermediate4 courses
TRACK SE · 28 weeks

Software engineering

How software is planned, modelled, built and shipped by teams rather than individuals.

  • Git, GitHub and working in the open
  • Software modelling and system design
  • Mobile app development
  • Testing, CI and deployment
Foundation to advanced4 courses
TRACK DB · 22 weeks

Data and databases

Store information properly, serve it safely, and turn it into reports people act on.

  • Databases and SQL
  • Backend APIs and data services
  • Data analysis and reporting
Foundation to advanced3 courses
TRACK AI · 24 weeks

Artificial intelligence

From what a model actually is to shipping an application built on one, with ethics throughout.

  • Foundations of artificial intelligence
  • Python for machine learning
  • Building with large language models
Foundation to advanced3 courses
TRACK AG · 14 weeks

Agentic systems

Design software that plans, calls tools and automates work under human supervision.

  • Agentic systems and tool use
  • Automating real workflows
Advanced2 courses
TRACK DM · 10 weeks

Documentation and media

Write documentation people can follow and produce the video tutorials that carry it further.

  • Technical writing and documentation
  • Video tutorials and documentary learning
Foundation to intermediate2 courses

How study is structured

ElementWhat it means for you
Weekly lessonA written lesson you can read offline, released every Monday.
Video tutorialA recorded walkthrough of the same material, compressed for mobile data.
Practical taskOne piece of work pushed to your own repository and opened as a pull request.
Code reviewAn instructor comments on your code within five working days.
CapstoneA final project that solves a real problem in your community.
CertificateIssued on completion, with a link to the public work behind it.
