Why this university exists

A student in Gbarnga with a second-hand phone and a few hours of data should be able to learn the same skills as a student in a funded computer-science faculty anywhere else.

SDWSR was founded on 6 May 2025 by Dr. Samuel D. Wilson Sr. as an online university teaching frontend development. It has grown into a school covering the full path from a first web page to production software, data systems and applied artificial intelligence.

Every course is delivered through written lessons, recorded video tutorials and documentary-style teaching, with all coursework submitted through GitHub so that graduates leave with a public record of what they can build.

Read the university's story

Built for low bandwidth

Lessons are text-first, videos are compressed for mobile data, and every assignment can be completed on a mid-range Android phone or a shared computer.

Public, reviewable work

Assignments are submitted as pull requests. Instructors review code the way a working team does, and your repositories become your portfolio.

How a term works

1. Apply

Send one short application. No entrance exam, no fee to be considered.

2. Set up

You get a GitHub account in the university organisation and a Google Classroom seat.

3. Build weekly

Each week: a lesson, a video, and one piece of work you push to your repository.

4. Graduate with proof

Finish the track with reviewed code, a capstone project and a certificate.

Admissions are open for the next intake.

Applications are reviewed as they arrive and every applicant receives a reply.
